================================================================================
                    ফন্ট সেটিংস কোথায় আছে?
          WHERE TO CHANGE THE BENGALI NUMBER FONT?
================================================================================

📁 ফাইল: config.js
📍 লোকেশন: প্রজেক্ট ফোল্ডারের মূল ডিরেক্টরিতে

================================================================================
                         ঠিক এই লাইনটি খুঁজুন:
                  FIND THIS LINE (at the very end):
================================================================================

const BENGALI_NUMBER_FONT = "tiro-bangla";

^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

================================================================================
                    কীভাবে পরিবর্তন করবেন?
                  HOW TO CHANGE IT?
================================================================================

আপনার পছন্দ অনুযায়ী "tiro-bangla" এর জায়গায় বদলে দিন:

Choose ONE of these:

1. Tiro Bangla (সুন্দর, ঐতিহ্যবাহী) - DEFAULT
   const BENGALI_NUMBER_FONT = "tiro-bangla";

2. Hind Siliguri (আধুনিক, পরিষ্কার)
   const BENGALI_NUMBER_FONT = "hind-siliguri";

3. Baloo Da 2 (বড়, স্পষ্ট)
   const BENGALI_NUMBER_FONT = "baloo-da-2";

4. Custom (আপনার নিজস্ব ফন্ট)
   const BENGALI_NUMBER_FONT = "my-custom-font";

================================================================================
                      উদাহরণ: Hind Siliguri এ পরিবর্তন
                   EXAMPLE: Changing to Hind Siliguri
================================================================================

BEFORE (আগে):
   const BENGALI_NUMBER_FONT = "tiro-bangla";

AFTER (পরে):
   const BENGALI_NUMBER_FONT = "hind-siliguri";

================================================================================
                           পদক্ষেপ
                           STEPS
================================================================================

1️⃣  config.js ফাইল খুলুন (সাধারণ টেক্সট এডিটর বা VS Code)
    Open config.js file

2️⃣  শেষ দিকে এই লাইনটি খুঁজুন (প্রায় ২০০ লাইনের পর):
    Find this line near the end (around line 195-200):
    
    const BENGALI_NUMBER_FONT = "tiro-bangla";

3️⃣  "tiro-bangla" এর জায়গায় আপনার পছন্দের ফন্ট নাম লিখুন
    Replace "tiro-bangla" with your choice:
    
    ✓ "tiro-bangla"
    ✓ "hind-siliguri"
    ✓ "baloo-da-2"

4️⃣  ফাইল সংরক্ষণ করুন (Ctrl+S)
    Save the file (Ctrl+S)

5️⃣  ব্রাউজার রিফ্রেশ করুন (Ctrl+F5 - hard refresh)
    Refresh browser (Ctrl+F5 - hard refresh for cache clear)

6️⃣  নতুন রেজাল্ট কার্ড খুলুন এবং সংখ্যাগুলি দেখুন!
    Open result card and see the new font!

================================================================================
                      ফন্ট পরিবর্তন হলো কী হবে?
                 WHAT HAPPENS AFTER FONT CHANGE?
================================================================================

শুধুমাত্র এই সংখ্যাগুলি পরিবর্তিত হবে:
Only these numbers will change:

✅ রোল নম্বর (Roll Number)
✅ সংখ্যা নম্বর (Marks)
✅ মোট নম্বর (Total)
✅ র‍্যাঙ্ক (Rank)
✅ পার্সেন্টেজ (Percentage)

এগুলি পরিবর্তন হবে না:
These will NOT change:

❌ স্কুলের নাম
❌ বিষয়ের নাম
❌ ছাত্রের নাম
❌ গ্রেড (A+, B, C)
